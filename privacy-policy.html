轻量沉浸翻译

隐私政策

生效及更新日期：2026 年 11 月 2 日 适用扩展版本：0.6.0

本政策说明“轻量沉浸翻译”（下称“本扩展”）在提供网页双语翻译、划词翻译与词典、PDF 双语阅读和 YouTube 双语字幕时，如何访问、使用、存储及传输数据。

设置保存在本机；主动翻译时，相关文本会发送至您选择的服务。

本扩展没有用于汇集翻译内容的开发者后台，不要求注册本扩展账号，不植入广告或行为分析 SDK，不出售用户数据。第三方翻译、词典、音频及文档来源服务仍会接收到完成相应请求所需的数据。

1. 适用范围与处理目的

本政策适用于本扩展自身的数据处理。我们仅为提供用户主动使用的翻译、查词、发音及阅读功能访问必要数据。第三方服务对其接收到的数据的处理，以及托管本政策页面的平台对访问日志的处理，受相应服务方的政策约束。

本扩展不通过浏览历史 API 建立访问记录，不读取浏览器 Cookie 作为翻译凭据，也不为广告、画像或跨站追踪收集浏览活动。

2. 本地存储的数据

本扩展使用浏览器的 chrome.storage.local 保存以下配置，以便在重启浏览器后继续使用：

  • 所选翻译服务、目标语言和划词翻译开关。
  • 您填写的 AI 服务地址、模型名称、API Key，以及自建 LibreTranslate 地址和可选 API Key。
  • 用于识别设置变化的配置版本标识。

这些配置不通过本扩展的 Chrome 同步存储上传。API Key 仅在调用其对应的已配置服务时发送给该服务；不会因选择微软或谷歌翻译而把已保存的 AI Key 一并发送。本扩展限制普通网页内容脚本直接读取上述本地配置。

3. 各功能处理的数据

网页双语翻译

本扩展在普通 HTTP/HTTPS 网页显示翻译入口。您主动开启网页翻译后，扩展在本地提取页面中符合条件的文字段落，将待翻译文本发送至当前所选翻译服务，并把译文显示在原文附近。未开启翻译时，不向翻译服务发送网页正文；还原或取消操作会停止后续任务，但不能撤回已发出的请求。

划词翻译与词典发音

选中文字本身不会发起翻译或查词。点击选区旁的熊猫按钮后，句子或段落仅发送所选文本；英文单词发送至 Free Dictionary API 查询。需要中文义项时，词典返回的英文释义会发送至当前所选翻译服务。

只有主动点击词典发音按钮时，扩展才请求词典提供且在允许来源内的音频。手动选择“本机朗读”时，扩展仅选用浏览器标记为本机的英语声音。本扩展不保存查词历史。

PDF 双语阅读

您选择的本地 PDF 在浏览器内解析；通过在线地址打开 PDF 时，浏览器会从该地址获取文件。点击“翻译当前页”后，当前页提取出的待翻译文字会发送至所选翻译服务，不会为翻译而上传整个 PDF 文件。打开加密 PDF 时输入的文档密码仅用于本地解析，不随翻译请求提交。

YouTube 双语字幕

您主动开启字幕翻译后，扩展读取当前显示的字幕文字并发送至所选翻译服务，以显示双语字幕。本扩展不为该功能上传视频或音频，也不进行语音识别。

服务连接测试与请求范围

设置页的“测试连接”向您正在测试的服务发送固定短文本，不读取当前网页正文。翻译和词典接口请求不附带网页 Cookie、表单字段、整页 HTML 或当前网页地址作为额外上下文；文本本身可能含有您所选择或页面正文中已有的个人信息。

5. 权限用途

  • storage：在本机保存第 2 节列出的设置与服务凭据。
  • activeTab：在您打开扩展工具栏弹窗时访问当前活动标签页信息，识别当前 PDF 地址，并配合当前页面的状态显示及字幕操作。
  • HTTP/HTTPS 主机访问权限：在不同网站显示翻译和划词入口，按用户操作读取待翻译内容、显示译文，以及连接翻译、词典、发音、在线 PDF 和用户自定义服务。自定义服务与文档地址并非固定域名，因此权限覆盖普通 HTTP/HTTPS 网站。

这些权限仅用于上述功能。本扩展的可执行 JavaScript 和 PDF.js 所需的 WebAssembly 等资源随安装包提供，不从远程服务器下载并执行更新代码；在线翻译响应按数据处理。

6. 数据留存与安全

本扩展不将网页原文、译文、字幕、PDF 文本或查词记录写入持久化历史库。处理任务期间，相关内容可能暂存在页面或扩展后台内存中，用于显示结果、缓存当前结果或取消任务；关闭相关页面、重载扩展或相应运行环境释放时，这些临时数据随之释放。浏览器或第三方服务自身的缓存及日志由其管理。

本地设置会保留至您修改、清除扩展数据或卸载扩展。API Key 存储在浏览器本地扩展存储中，本扩展未对其提供额外的应用层加密。

内置微软、谷歌、词典与音频接口使用 HTTPS，自定义 AI 地址要求 HTTPS。当前版本允许用户为 LibreTranslate 配置 HTTP 或 HTTPS，也允许通过 HTTP 地址打开在线 PDF；HTTP 请求不提供传输加密。请为远程自建服务和在线文档选择可信的 HTTPS 地址，并只向所选服务提交您有权处理的内容。

7. 您的选择与删除方式

  • 控制发送：按需开启网页、划词、PDF 或字幕翻译；关闭划词开关或取消任务可停止后续请求。
  • 选择接收方：在设置页选择翻译引擎并查看服务地址；自建服务的数据处理由您选择的实例运营者负责。
  • 清除配置：在设置页点击“清除 AI 密钥”或“清除 LibreTranslate 密钥”可删除对应的已保存密钥；也可清空相应 API Key 输入后保存。清除扩展本地数据或卸载扩展可删除全部本地配置。原服务商签发的密钥如需失效，请在该服务商处撤销。
  • 限制网页访问：在 Chrome 的扩展程序管理页调整本扩展的网站访问权限，或停用、卸载本扩展；限制权限可能使相应翻译功能不可用。
  • 处理第三方留存：如需查询或删除已提交给第三方服务的数据，请联系实际服务运营者；本地删除无法撤回已经完成的网络请求。

8. 数据使用限制

本扩展访问、使用和传输用户数据，仅限于提供本政策所述的翻译与阅读功能。我们不出售用户数据，不将其用于个性化广告、与核心功能无关的画像、数据经纪业务、信用评估或贷款用途。

本扩展对通过 Google API 接收的信息的使用将遵守 Chrome 网上应用店用户数据政策，包括“有限使用”（Limited Use）要求。

9. 政策变更

功能或数据处理方式发生变化时，我们会更新本政策及页面顶部日期。如果变更涉及新增数据用途或接收方，我们会按适用要求更新扩展内说明，并在需要时取得用户同意。请以与您正在使用的扩展版本相匹配的说明为准。
