# 发音失败修复

用户反馈词典发音和本机朗读均失败，按 systematic-debugging 先诊断后修复，不改变已选划词布局。

## 已复现原因

- 词典音频中转同地址 HTTP 502，无重定向；原始 Commons 音频 HTTP 200。
- Commons 返回 application/ogg，旧下载器拒绝；真实数据来源关联未保留在单条音标。
- 真实扩展在 media-src none 网页中播放 data URL 被 CSP 拦截。
- Edge／Chrome 当前枚举只有三个中文本机声音，没有英语声音；旧筛选返回空。显式使用本机 Huihui 朗读 hello 可 start/end。

## 修复与验证

- [x] 保留每条音标的原始来源，用户点击后从固定 Commons 元数据解析受限原文件，支持可验证的 Ogg 音频；不放开任意重定向或更换词典服务。
- [x] 扩展 offscreen 播放，不受网页 media-src 影响；播放与停止绑定原请求，关闭、换词、导航后不复活旧声音。
- [x] 本机英语声音优先；缺少英语时使用本机默认声音并可见标明合成与语言，不调用在线语音。
