# YouTube 双语字幕

目标：在已有轻量沉浸翻译扩展中支持 YouTube 桌面播放页字幕翻译，参考用户截图的原字幕＋译文双行阅读方式。复用已保存引擎与目标语言。

入口：YouTube 播放页点击侧边熊猫或播放器内的小“译”按钮开启字幕翻译，再次点击关闭。默认关闭；只在用户开启后读取并翻译当前字幕。播放器内提供必要状态、重试和打开原有设置的入口，不复制竞品的付费、请求 AI 字幕、下载等工具。

数据与生命周期：读取 YouTube 原生已发布字幕／自动字幕的可见文字；不生成语音识别，不读取评论和表单，不请求整份视频转录。可见字幕按短防抖合并更新，一次最多一个在途批次并仅保留最新待处理字幕；旧字幕回复不可显示在新句、跳转或关闭后的画面。只保留有限内存缓存；设置变化和切换视频后取消并清理。原文和译文为纯文本，密钥仍只由后台使用。

显示：原文＋译文置于播放器内部，支持剧场及全屏，关闭后恢复原生字幕。如需要开启原生 CC，仅在用户开启翻译时操作；关闭时恢复插件修改的状态，尊重用户后续操作。没有可用字幕时明确提示，不能承诺对无字幕视频识别语音。无需增加扩展权限。

兼容：普通网页与 PDF 入口保持已有行为；普通网页正文翻译必须跳过播放器、原生字幕和自有字幕浮层。YouTube 内部导航、播放器延迟出现／替换和切换语言必须处理。

验证：模拟 YouTube 实际播放器 DOM 的真实浏览器测试覆盖默认不发送、可信点击、字幕更新、缓存、延迟回复、取消、跳转、配置变化、没有字幕和全屏归属；现有网页/PDF/熊猫交互回归；安装包包含新文件。可进行真实站点只读观察，不向外部服务发送未授权的视频字幕。
