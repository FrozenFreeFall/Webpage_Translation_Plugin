# PDF 翻译设计

用户选择第一张草图，并确认原生 PDF 页面可以显示熊猫。直接沿用该入口：在 Chrome / Edge 浏览 PDF 时点击熊猫，在新标签打开扩展阅读器，保留原页。支持在线 PDF 与手动选择本地文件。

默认“双语对照”：原 PDF 页与译文左右同步阅读。另提供“双语阅读”：每段原文后显示译文，代码保持原文。两种模式共用当前页翻译结果，切换不重复请求。目录可折叠，支持跳页、前后翻页、缩放。沿用浅紫白、靛蓝按钮与现有设置。

PDF.js 随扩展本地打包；原稿由 canvas 渲染。文字按行与段落提取，代码不发送翻译。仅显式开始翻译后发送当前页可翻译文字，复用后台已保存引擎与目标语言，禁止 PDF 页读取密钥。取消、翻页、换文件或配置变更使旧请求失效；失败段落可重试。扫描件显示暂无可提取文字，不承诺 OCR 或全文导出。

选择：左右对照适合核对技术文档，是默认；单栏双语适合连续阅读，是可切换模式；不采用独立译文侧栏。首次优先可读性，不承诺译文与原稿逐像素排版一致。文件解析、正文和译文均不持久化。

验证：PDF 熊猫跳转、URL 验证、文档级会话隔离、本地/在线载入、真实 PDF 解析、双模式共用结果、取消/错误/配置变更、打包资产完整性。浏览器原生 PDF 熊猫可显示这一点采用用户确认，不再核实。
